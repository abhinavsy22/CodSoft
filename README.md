# CodSoft ML Internship Tasks

This repository contains all machine learning tasks completed as part of the **CodSoft ML Internship**.

---

## Tasks

### Task 1 - Movie Genre Classification
> Predict the genre of a movie based on its plot summary using NLP.

- **Techniques**: TF-IDF Vectorization (unigrams + bigrams)
- **Models**: Naive Bayes, Logistic Regression, SVM (LinearSVC)
- **Dataset**: [IMDB Genre Classification Dataset](https://www.kaggle.com/datasets/hijest/genre-classification-dataset-imdb)
- **Folder**: `Task-1-Movie-Genre-Classification/`

---

## How to Run

```bash
cd Task-1-Movie-Genre-Classification
pip install -r requirements.txt
python movie_genre_classification.py
```
