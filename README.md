# CodSoft ML Internship Tasks

This repository contains all machine learning tasks completed as part of the **CodSoft ML Internship**.

---

## Tasks

### Task 1 - Movie Genre Classification
> Predict the genre of a movie based on its plot summary using NLP.

- **Techniques**: TF-IDF Vectorization (unigrams + bigrams)
- **Models**: Naive Bayes, Logistic Regression, SVM (LinearSVC)
- **Dataset**: [IMDB Genre Classification Dataset](https://www.kaggle.com/datasets/hijest/genre-classification-dataset-imdb)
- **Folder**: `Task-1-Movie-Genre-Classification/`

---

### Task 2 - Credit Card Fraud Detection
> Detect fraudulent credit card transactions using classification algorithms.

- **Techniques**: Feature Engineering (time, age), Class Imbalance Handling
- **Models**: Logistic Regression, Decision Tree, Random Forest
- **Dataset**: [Credit Card Fraud Detection Dataset](https://www.kaggle.com/datasets/kartik2112/fraud-detection)
- **Folder**: `Task-2-Credit-Card-Fraud-Detection/`

---

### Task 3 - Customer Churn Prediction
> Predict whether a bank customer will churn using historical data.

- **Techniques**: One-Hot Encoding, Standard Scaling, Class Imbalance Handling
- **Models**: Logistic Regression, Random Forest, Gradient Boosting
- **Dataset**: [Bank Customer Churn Prediction](https://www.kaggle.com/datasets/shantanudhakadd/bank-customer-churn-prediction)
- **Folder**: `Task-3-Customer-Churn-Prediction/`

---

## How to Run Any Task

```bash
cd Task-X-<TaskName>
pip install -r requirements.txt
python <script_name>.py
```

> **Note:** Download the dataset from Kaggle and place it in the `data/` subfolder of each task directory before running.
